# Регламент синхронизации с upstream анлокером (AvenCores/open-antigravity-patcher)

Данный регламент предназначен для ИИ-агента Antigravity (`.agent`) при запросах пользователя вида:
* «Проверь обновления анлокера»
* «Синхронизируй с upstream»
* «Подтяни новые патчи из open-antigravity-patcher»

## 🔒 Политика конфиденциальности и локальности (Zero-Leak Policy)
1. **Никаких автоматических сетевых запросов в рантайме приложения**: Десктопное приложение (GUI) и CLI Antigravity Toolkit работают строго офлайн и локально.
2. **Только ручной запуск через агента**: Проверка апстрима и накат обновлений осуществляются исключительно вручную по прямой команде пользователя через Git.
3. **Сохранение локализации и интерфейса**: При слиянии запрещено перезаписывать русские переводы (`frontend_bundle/`, `patcher/manager/patcher.py`), графический интерфейс (`gui/`) и подсистемы защиты данных (`patcher/backup/`, `patcher/accounts/`).

---

## 🛠 Пошаговый протокол для Агента

### Шаг 1: Запуск скрипта сверки
Выполнить команду в терминале:
```bash
python3 scripts/check_upstream.py
```
Скрипт выполнит безопасный `git fetch upstream --tags` и выведет список новых коммитов и затронутых файлов ядра.

### Шаг 2: Анализ изменений ядра
Если обнаружены изменения в патчерах (`patcher/manager/`, `patcher/ide/`, `patcher/agy/`, `patcher/vscode/`):
1. Запустить просмотр диффа для конкретного файла:
   ```bash
   git diff HEAD...upstream/main -- patcher/manager/patcher.py
   ```
2. Проверить, появились ли новые сигнатуры байт (`find_pattern`, `SIGNATURES`), новые смещения или логика атомарной записи.

### Шаг 3: Ручной перенос изменений (Porting)
1. Перенести полезные изменения логики (например, новые сигнатуры для новых версий Antigravity) в локальные файлы проекта.
2. Сохранить русскоязычный вывод в консоль (`ok()`, `info()`, `warn()`, `err()`).
3. Сохранить все хуки для GUI (`--json-status`, события бэкапов).

### Шаг 4: Обновление версии
Если в upstream вышел новый релизный тег (например, `V1.3.7`):
1. Обновить константу `VERSION` в `patcher/constants.py`.
2. Обновить версию в `package.json`.

### Шаг 5: Тестирование и пересборка
1. Проверить работоспособность CLI:
   ```bash
   python3 main.py --diagnostics
   python3 main.py --json-status
   ```
2. При необходимости пересобрать локальный macOS-бандл:
   ```bash
   ./build_gui_macos.sh
   ```
3. Предоставить пользователю отчет о добавленных сигнатурах и изменениях.
