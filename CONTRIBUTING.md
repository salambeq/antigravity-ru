# Правила участия и внесения изменений (Contributing Guidelines)

Благодарим вас за интерес к проекту **Antigravity Toolkit & Localization**!

## ⚠️ Важное лицензионное ограничение
В соответствии с лицензией проекта ([LICENSE](LICENSE)):
- **Внесение любых изменений в исходный код программы третьими лицами без предварительного письменного согласия Автора (@salambeq) СТРОГО ЗАПРЕЩЕНО.**
- Запрещается публикация и распространение модифицированных копий (форков) программы без явного разрешения.

## 💡 Как предложить улучшение или сообщить об ошибке:
1. **Сообщение об ошибках (Bug Reports)**:
   - Если вы обнаружили баг, создайте [Issue](https://github.com/salambeq/antigravity-ru/issues) с подробным описанием:
     - Версия операционной системы (macOS / Linux / Windows).
     - Версия Antigravity и Toolkit.
     - Шаги для воспроизведения и текст ошибки из консоли.
2. **Предложение новых функций (Feature Requests)**:
   - Создайте [Issue](https://github.com/salambeq/antigravity-ru/issues) с тегом `enhancement`, подробно опишите сценарий использования и обоснуйте необходимость функции.
3. **Пулреквесты (Pull Requests)**:
   - **Перед созданием любого Pull Request обязательно свяжитесь с Автором** через обсуждение в Issues и получите подтверждение.
   - Пулреквесты, отправленные без предварительного согласования с Автором, могут быть отклонены без рассмотрения.
