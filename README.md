# Antigravity 2.0 — Русская локализация (Russian Localization)

🇷🇺 Полная локализация десктопного приложения **Google Antigravity 2.0** на русский язык.

Репозиторий содержит автоматические скрипты для перевода интерфейса программы, переключения языков в один клик, набора глобальных правил разработки на русском языке и навыка интернационализации проектов (`i18n-helper`).

---

## 🌟 Что переведено

1. **Нативный слой Electron (`app.asar`)**:
   - Главное меню macOS (пункты «Новое окно», «Документация», «Проверить обновления»).
   - Системный трей и Dock («Нет активных агентов», «N активных агентов», «Открыть Antigravity», «Выйти»).
   - Системные диалоги (подтверждение выхода, диалоги выбора рабочих папок).
   - Центр обновлений (статусы проверки, скачивания и установки).
   - Runtime-мост в `preload.js` для динамического перевода всплывающих подсказок (`placeholder`, `title`, `aria-label`).

2. **Веб-интерфейс и холст агента (`language_server`)**:
   - Сайдбар навигации («Новый чат», «История диалогов», «Запланированные задачи», «Плагины UI», «Автоматизации», «Настройки»).
   - Холст чата и шаги выполнения («Принять шаг», «Отклонить шаг», «Принять все», «Отклонить все», «Требуется действие», «Размышляет...», «Выполняется команда...»).
   - Вспомогательные вкладки («Подагенты», «Фоновые задачи», «Артефакты», «Изменённые файлы», «Терминалы»).
   - Все экраны и параметры настроек (песочница, списки команд, звуки, ширина диалога, выбор тем и т.д.).

## 🚀 Быстрый старт

### 1. Переключение языков
В репозитории доступен скрипт для мгновенного переключения языка:

```bash
# Включить русский язык:
./switch_lang.sh ru

# Вернуть оригинальный английский язык:
./switch_lang.sh en
```
*После переключения перезапустите Antigravity (`Cmd + Q` и запустите снова).*

### 2. Применение патча (или обновление после апдейта Antigravity)
Если вышло новое официальное обновление Antigravity, запустите автоматический сборщик патча:

```bash
./apply_patch.sh
```
Скрипт автоматически:
- Создаст резервные копии оригинальных файлов (`app.asar.orig`, `language_server.orig`);
- Распакует бандл и применит актуальные переводы;
- Пересоберёт и подпишет бинарные файлы системной подписью Apple (`codesign`);
- Проверит целостность и установит обновление.

### 3. Откат к исходному состоянию
Чтобы мгновенно вернуть программу к оригинальному заводскому состоянию:

```bash
./restore_original.sh
```

## 🛠 Архитектура решения

Antigravity 2.0 состоит из оболочки Electron и локального сервера ядра на Go (`language_server`):
- `language_server` содержит встроенный ZIP-архив с веб-приложением (React/Closure Library, ~9 МБ).
- `patch_binary.py` извлекает этот архив, накладывает переводы через `localize_frontend.py`, сжимает заново (Deflate level 9), записывает обратно в бинарник со смещения `118051885`, обновляет Go-слайс структуры данных и подписывает бинарник через Apple `codesign`.
- `patch_asar.py` локализует меню, трей, диалоги и внедряет MutationObserver в `preload.js`.
